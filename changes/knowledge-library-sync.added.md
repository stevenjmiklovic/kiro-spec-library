Added Knowledge Library sync: push specs into the KiroCrew Knowledge Library (graph-based, embeddings-optional store) as one document per spec — normalized metadata, typed relationships (named by spec ID so specs cross-link in the graph), and full requirements/design/tasks bodies. Idempotent via a stable per-spec `source_uri` (unchanged specs are refused as duplicates). Exposed as a per-spec "Send to Knowledge Library" button in the spec actions panel (`POST /api/knowledge-sync/spec`) and a batch `POST /api/knowledge-sync` endpoint.
